# Minimine Bench 1.0.0

1. **MinimineBench.hh3** auf den CP400 kopieren und im Hollyhock-3-Launcher starten.
2. **EXE** startet alle zwoelf Varianten mit drei Durchlaeufen.
3. Nach Abschluss das Programm beenden und den Ordner **MinimineBench** vom
   Rechner kopieren. Alle vier Dateien desselben Laufs an mich schicken;
   alternativ den Ordner als ZIP senden.

Mit hoch/runter kann ein einzelner Durchlauf fuer den ersten Funktionstest
gewaehlt werden. Links/rechts waehlt einzelne Varianten. CLEAR bricht ab und
sichert die Teilmessung; im Hauptmenue beendet CLEAR das Programm.

Minimine und seine Spielstaende werden nicht veraendert.
