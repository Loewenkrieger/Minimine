# Minimine 0.5.1

`CasioSandbox.hh3` auf den CP400 kopieren und ueber Hollyhock 3 starten.
Bestehende Spielstaende koennen weiterverwendet werden.

Mobgrafiken und Beleuchtung werden effizienter gezeichnet. Die Darstellung
bleibt pixelgleich; die Grafikpuffer bleiben unter 20 KiB. Die FPS-Verbesserung
wird mit dem kurzen Alt/Neu-Vergleich von Minimine Bench 1.1.0 gemessen.
