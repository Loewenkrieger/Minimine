# Minimine 0.5.2

Nur `CasioSandbox.hh3` auf den CP400 kopieren und ueber Hollyhock 3 starten.
Spielstaende von 0.5.0 und 0.5.1 bleiben verwendbar.

Die langsamere Beleuchtungsaenderung aus 0.5.1 wurde zurueckgenommen.
Block-/Moboptimierungen bleiben erhalten, bei gleicher Darstellung und
unveraendertem Grafikbudget. Der neue Lichtversuch ist nur im Benchmark
enthalten. Die Geschwindigkeit dieser Kombination muss am Geraet gemessen werden.
