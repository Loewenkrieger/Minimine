# Minimine 0.5.3

Nur `CasioSandbox.hh3` auf den CP400 kopieren und mit Hollyhock 3 starten.
Vorhandene Spielstaende bleiben ladbar; ein neues Spiel ist nicht erforderlich.

Die zeilenweise Beleuchtung aus Minimine Bench 1.2.0 ist jetzt im Spiel aktiv.
Sie erreichte in den beiden beleuchteten Tests rund 18 Prozent mehr FPS als
der Lichtpfad von 0.5.2. Darstellung, Spielmechanik und Speicherformat bleiben
gleich; der Grafikcache bleibt bei 20.370 Bytes.

Alle Spiel- und Bildtests bestanden. Die Geschwindigkeit im eigenen Spielstand
bitte an derselben Position wie unter 0.5.2 vergleichen. Der separate Benchmark
muss nicht erneut ausgefuehrt werden.
